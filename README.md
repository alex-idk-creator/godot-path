# Godot Path

Бесплатный русскоязычный учебный сайт: 50 уроков и 10 пошаговых гайдов по Godot и Orchestrator.

Открыть: https://alex-idk-creator.github.io/godot-path/

## Запуск и проверки

Нужен Node.js 22 или новее. Зависимостей и сборки нет.

- `npm run check` — проверка полноты курса и синтаксиса.
- `pnpm run site:ensure` — оставить локальный сайт на http://127.0.0.1:5181/.
- `npm run dev` — сервер в текущем терминале.

GitHub Pages публикует корень ветки `main`. Прогресс, закладки, тема и текущий шаг хранятся в localStorage данного браузера. Перенос между устройствами и аккаунты не реализованы. Сайт не подключён к редактору Godot: практические действия ученик отмечает самостоятельно.

## Учебная версия

Godot 4.7.x + Orchestrator 2.5.x; при использовании иной пары сверяйтесь с официальной таблицей совместимости. Источники привязаны к каждому материалу. Иллюстрации — собственные учебные схемы, не снимки редактора.

Визуальное направление взято из авторского CFOP Guide: светлая/тёмная темы, бирюзовый акцент, сдержанные карточки. От Duolingo используется идея короткого учебного пути с прогрессом; чужие персонажи и фирменные изображения не используются.
