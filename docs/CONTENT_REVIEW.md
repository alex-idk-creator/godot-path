## Проверка в движке

Официальные архивы Godot 4.7.2 и demo Orchestrator v2.5.stable скачаны в игнорируемую `artifacts/editor-qa/`. Программы пользователя не заменялись. Движок запущен с `--headless --audio-driver Dummy --fixed-fps 60`; звук не воспроизводился.

14 проверок прошли в реальном движке:

1. Нативное расширение регистрирует Orchestrator.
2. Настоящий граф .torch выполняет New ConfigFile → set_value → save; возвращает OK; записанное графом число 42 читается обратно.
3. Официальный шаблон Basic Movement загружается. Перед загрузкой служебные `_GUIDn_` заменены UUID, как это делает создание из шаблона; содержимое логики не изменялось.
4. Капсула падает на коробку пола и остаётся на полу.
5. Прыжок начинается с пола.
6. Повторное нажатие в воздухе не даёт второго прыжка.
7. Диагональ сохраняет скорость 5.
8. Копия материала меняется независимо.
9. Отсутствующая ссылка может быть проверена.
10. Обнуление velocity и запись global_position возвращают тело к точке.
11. ConfigFile сохраняет рекорд.
12. Новый экземпляр ConfigFile читает сохранённое значение.
13. Отсутствующий ключ использует default 0.
14. Отсутствующий файл возвращает ERR_FILE_NOT_FOUND.

Итоговый запуск не содержит ERROR/WARNING. Первый headless-импорт официального demo показал сообщения об утечках ресурсов интерфейса при завершении редактора; это отдельно от успешного запуска проверок логики и не скрывается как «все проверки без предупреждений».
