## Учебные рамки

Godot 4.7.x + Orchestrator 2.5.x: таблица совместимости в официальном репозитории. Orchestrator — GDExtension, не обычный GDScript-плагин. Файлы графов .torch. Сайт объясняет работу в отдельном редакторе, не подключается к Godot и не проверяет файлы ученика автоматически. Завершение практики отмечает сам ученик; ответы проверяются на сайте.
